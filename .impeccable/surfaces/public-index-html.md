# Surface: 前台抽經文（public/index.html）

Scope: 前台全流程（首頁 → 划船 → 下網 → 經文卡，及關閉／測試模式狀態）。Visitor mode: Experience。
Audience/job: 跨年禱告會現場會眾（含長輩），手機上領受一則祝福經文並保存分享。
Constraints: 無聲，經文出現時輕震；首頁一眼看懂怎麼抽；不卡通、字大對比足、裝飾不蓋過經文；抽完不能等太久。
Unresolved: 12 月教會設計組將出主視覺，屆時以此為參考重新設計；配色集中在 css/theme.css。

## Direction contract

THESIS: 使用者親手把小船划進水深之處，下網後在金光中領受一則經文；整個過程是一個小小的儀式。沿用範例網頁的夜海世界，不另起爐灶。

OWN-WORLD: 深藍夜海漸層（越深越暗）、上升的微光氣泡、流動海浪線、金色發光魚群、破曉金光；金色漸層膠囊按鈕；深藍底金色雙框的祝福經文卡；思源宋體標題與經文，系統黑體小字。

STORY: 看到 logo 與「進到水深之處」→ 按啟航 → 按住小船往上划（或點一下自動划）→ 撒網、魚群入網、大魚躍起、金光 → 經文卡浮現、經文淡入 → 存圖、分享、複製；再進來永遠同一則，可再看一次航行。

FIRST VIEWPORT: 上方白色單色版 logo（直接放在夜海上）；中央錨形徽章、金色活動名、大字「進到水深之處」、副標、主題經文框；拇指區金色膠囊大按鈕「啟航領受經文」與一行說明。
